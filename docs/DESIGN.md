## 2. 布局栅格（硬约束，可自动断言）

```
┌──────────────────────────────────────────────────────────┐
│ 标题栏 32 | 动作岛 56（打开/解压/压缩/测试/查看/搜索）        │  ← 顶部合计 88
├──────────┬───────────────────────────────────────────────┤
│ 侧栏 220 │ 内容区（列表或网格）                            │
│ 可折叠    │ 列表：行高 36，缩进 20，列宽 名称* / 大小 / 压缩率 / 时间 │
│ 折叠后 0  │ 网格：tile 自适应 96–192，最小列宽 120            │
│          │ 内容区四周 padding 16，岛之间 gap 12             │
├──────────┴───────────────────────────────────────────────┤
│ 状态条 28（文件 N / 文件夹 M / 压缩包大小 X）                 │
└──────────────────────────────────────────────────────────┘
```

**C128**：状态条只回答"我在看什么"——当前目录的**文件数/文件夹数**和**整包压缩后大小**；
加密/方法/字典/压缩率只出现在侧栏信息卡上，且信息卡**默认折叠成一行**（点击展开），
折叠状态写入 `window.infoCardExpanded`。

**可以写成断言的**：
- 任意两个同级矩形**不相交**（overlap 断言，容差 0）
- 内容区内所有条目矩形必须落在内容区矩形之内（clipping 断言）
- 侧栏折叠后内容区宽度 = 窗口宽 - 32（无残影）
- 网格列数 = floor((内容宽 + gap) / (minTile + gap))，且 ≥1

### 2.1 标签栏（C60）：动作岛之上、标题之下

```
┌──────────────────────────────────────────────────────────┐
│ 标题栏 32                                                 │
├──────────────────────────────────────────────────────────┤
│ 标签栏 32   [ a.7z ×][ b.7z ● ×][ c.7z ×]        ← 无归档时整条不存在 │
├──────────────────────────────────────────────────────────┤
│ 动作岛 56（打开/解压/压缩/测试/查看/搜索）                    │
└──────────────────────────────────────────────────────────┘
```

- **位置**：标题栏之上没有别的东西，动作岛之上只有这一条。标签栏的矩形由
  `prism::layout::Compute(...)` 的第六个参数 `tabBarVisible` 决定
  （`WindowLayout.hpp`，唯一的几何权威）：可见时 `tabBar = [0,32] × [0,w]`、
  动作岛下移到 `top = 64`；**未打开归档时 `tabBar` 是空矩形（`Empty()`），
  动作岛回到 `top = 32`** —— 整条 32 px 不占位、不绘制。
- **高度 32**：与标题栏同阶；标签高度 20（上下各留 6），关闭按钮 16×16，
  右边距 8，标签间距 2，文字内缩 12。全部落在 §4 的间距阶（4/8/12/16）上。
- **宽度**：每个标签 = 可用宽 / 标签数，夹在 120–224 之间；超出的标签被裁切
  （命中测试只认栏内像素），标题按字符省略（DirectWrite 的 ellipsis sign）。
- **颜色（全部取自 C15 令牌，禁止字面量）**：
  | 部位 | 令牌 |
  |---|---|
  | 活动标签底 | `surface-floating-island` 复合在画布上（+1 px `border-specular-rim` 边） |
  | 非活动标签底 | `surface-canvas-base`（即画布底色；悬停时叠 45% 的岛色） |
  | 标题 | `text-primary`（活动）/ `text-secondary`（非活动） |
  | 脏标记圆点 | `accent-liquid-primary`，直径 6，位于关闭按钮左 12 px |
  | 拖拽插入位置 | `accent-liquid-primary`，2 px 竖条 |
- **交互**（规则全部由 `PrismCore/TabSet.hpp` 决定，界面只执行）：
  点击切换；点 × 关闭；中键关闭；`Ctrl+Tab` / `Ctrl+Shift+Tab` 循环；
  `Ctrl+W` 关闭当前；拖拽重排（拖动时显示插入位置）。
  脏标签关闭前走 C54 的确认框（`EditConfirmDialog`），取消则标签保留。
- **关闭最后一个标签 = 空状态**，不是退出程序：标签栏隐藏、视图清空、窗口保留。
- **可以写成断言的**（`c60.tab_bar`）：
  - 有 n 个标签时 `tabBar.Height() == 32`、`actionIsland.top == titleBar.bottom + 32`；
  - 没有标签时 `tabBar.Empty()`、`actionIsland.top == titleBar.bottom`；
  - 活动标签面（左缘内 5 px）= 岛色复合值，非活动标签 = 画布令牌值（容差 ≤2）；
  - 空状态下该带的像素里没有标签面、没有强调色（逐像素扫描计数为 0）。

## 3. 组件清单（每个都要有"空/加载/有数据/错误"四态）

| 组件 | 状态 | 数据来源 |
|---|---|---|
| 动作岛（Action Island） | 默认/悬停/按下/禁用 | 当前选择 + 归档状态 |
| 路径面包屑（Crumb） | 根/深层/空 | `tree::Navigator` |
| 列表视图 | 空/有数据/无缩略图 | `ListSortModel` + `FilterModel` |
| 网格视图 | 空/有缩略图/**无缩略图回退成行** | `ThumbStore` + `Gallery` |
| 侧栏 | 展开/折叠/空/收藏/最近 | `SidebarModel` |
| 信息卡（侧栏底部） | 折叠（一行）/ 展开（四行：加密/方法/字典/压缩率） | `SidebarModel::ComputeStatus` |
| 状态条 | 文件 N / 文件夹 M / 压缩包大小 X（当前目录 + 整包） | `Navigator::FolderItems` + catalog |
| HUD 胶囊 | 进行中/完成/失败（三阶段形变） | `ProgressHud` |

**P0 规则**：没有缩略图的条目**不得**画骨架卡；直接回退成一条 32px 的行（图标 + 名称 + 大小）。

## 5. 验收方式（比"看着挺好"硬）

1. **结构断言**（新增 `test_layout_invariants`）：overlap / clipping / 列数 / 折叠宽度，全用纯函数算矩形，不依赖渲染。
2. **像素断言**（扩 `gallery_snapshot`）：给定固定 catalog + 固定窗口尺寸，输出 PNG，断言关键区域的颜色（状态条背景、选中行高亮、岛边缘高光）而不是整图比对。
3. **人工要点**（每天一次，写进 PR 模板）：动作位置是否与 Bandizip 一致、密度是否够、玻璃是否有"层次"、动效是否跟手。
