## P1-1 CLI 动词碰加密包会弹模态密码框 → 无限挂死

- 复现：`PrismArchive.exe --test E:\Temp\prism-adtest\fixtures\enc.7z`（enc.7z 密码 PrismTest2026，不给密码）
- 实测：**进程挂死 >20 s**（模态密码框），Start-Process WaitForExit(20s) 超时后 kill。
- 交叉：`--compress-7z` 同类路径在 C71 已修过一次（GUI ask 提示进了 headless）——**同类坑的第二处入口**。
- 应为：CLI/headless 一律不弹框：stderr `encrypted: password required (supply via --password or vault)` + exit 2。
- 严重度：**P1**（批量脚本会永久挂起）。

## P2-1 多卷 7z（.7z.001/.002/.003）被引擎拒绝

- 复现：`PrismArchive.exe --smart-extract-each E:\Temp\prism-adtest\fixtures\vols.7z.001`
- 实测 stderr：
  `open: ext=.001 route=probe; sniff=7z [head=377abcaf271c]; 7z.Open hr=0x00000001; declined=7z reason=handler-rejected`
- 交叉验证：**真 7-Zip `7z t vols.7z.001` → Everything is Ok（1 文件 25000 B）**。
- 根因假设：桥把单卷当完整流交给 7z handler，handler 越卷寻址失败即拒；需要多卷拼接 IInStream
  （或按 7z.dll 的分卷打开约定），不是格式探测的问题。
- 严重度：**P2**（分卷是 C11/C2 的既定支持面）。
