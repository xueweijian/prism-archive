# 截图素材规范

README 里的四张图是**发布素材**，必须来自真实运行的本程序，不接受模拟图、占位图、
设计稿或从别家软件截来的图。拍好之前，README 只列文件名和「这张图要证明的事」，
不引用不存在的图片。

## 拍摄条件

| 项 | 要求 |
|---|---|
| 系统 | Windows 11，100% 缩放（或 125% 但在同一批里保持一致） |
| 窗口 | 1280 × 800 客户区，深色主题（Midnight），侧栏展开 |
| 内容 | 一个真实归档：至少 3 层目录、≥ 12 个条目、≥ 4 种类型（图片/文本/PDF/其它） |
| 语言 | 简体中文界面 |
| 格式 | PNG，单张 ≤ 500 KB，不做锐化/滤镜/拼接 |

拍摄方式：@@Alt+PrintScreen@@ 抓活动窗口，或 @@Win+Shift+S@@ 框选窗口。
不要用手机拍屏幕。

## 脱敏（硬要求）

- 不出现真实用户名、家目录、邮箱、机器名、许可证/序列号、内网地址。
- 路径用示例盘符：@@D:\Downloads\demo.7z@@、@@D:\work\project\@@。
- 窗口标题里的归档名用 @@demo.7z@@，不用客户项目名。
- 状态栏与预览里的文件名同样要检查：一个真实的客户名比一个可见路径更糟。

## 提交前自查

1. 四张图的窗口尺寸一致（像素宽高相同）。
2. 每张图都能在**未修改的**发布构建上复现同一画面（不是某个本地分支的临时 UI）。
3. 图片里的版本号与 README 写的版本一致。
4. 没有第二台显示器的边缘、没有鼠标指针、没有通知弹窗。
