## 三条最容易踩的坑（写在这里防止有人再踩）

- 两张截图都是 **125% DPI**，逻辑 px = 设备 px ÷ 1.25；
- 两个窗口尺寸不同（1732×1011 vs 1007×742），**比绝对像素会夸大差异**，要按占窗高百分比归一化；
- Bandizip 的蓝不是品牌色，是 `#0078D7` 叠 36% 白光泽——**白字对比度从 4.50 掉到 2.57**，别照抄。
